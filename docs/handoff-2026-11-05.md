### 启动开发态（推荐）

```bash
cd /d/dsc
pnpm run build          # tsc + 运行时包 + 插件包，产物落 lib/
pnpm run build:ui       # 界面壳，产物落 lib/ui/assets
cd desktop && pnpm dev  # electron-vite dev，窗口自己弹出来
```

**坑**：如果报 `Cannot read properties of undefined (reading 'requestSingleInstanceLock')`，
不是代码坏了，是环境里带了 `ELECTRON_RUN_AS_NODE=1`（Electron 被当纯 Node 跑）。
实测本机某个 Electron 宿主派生的终端会带上它，清掉即可：`env -u ELECTRON_RUN_AS_NODE pnpm dev`。
2026-11-05 17:46 实跑验证：`[+1297ms] 首帧已画出，窗口显示`，宿主界面地址 `http://127.0.0.1:<随机端口>`。

### 启动打包态 / 桌面快捷方式为什么打不开

快捷方式指向 `D:\dsc\desktop\dist\win-unpacked\Pneuma.exe`，目标文件在，但**那个目录被截断了**：

- 正常 Electron 目录该有 `icudtl.dat`、`resources.pak`、`chrome_100/200_percent.pak`、
  `locales/`、`snapshot_blob.bin`、`v8_context_snapshot.bin`、`vulkan-1.dll` —— 现在**一个都没有**；
- `resources/dsc-core/` 只剩 `node_modules/@koromix` 一个文件（应 2933 个、30 MB）；
- `debug.log` 从 `1103/185415` 起每次启动都是同一句
  `Invalid file descriptor to ICU data received`，然后进程直接退出、不弹窗不报错。

这是**一次中断的重新打包**留下的现场（`win-unpacked` 目录 mtime 11-03 18:54，dist 里的安装包还是
0.8.0、11-03 12:45；electron-builder 组装前会清空目标目录再拷，跑一半被杀就是这个残局）。
不是代码问题，重打一次就好：

```bash
cd /d/dsc/desktop
pnpm dist:dir       # electron-vite build + prepare-runtime + electron-builder --dir
```

产物回到同一路径，快捷方式即可用。`desktop/runtime-staging/dsc-core` 是完好的（0.8.1），
不需要重新 `prepare-runtime` 的输入。快捷方式本身由 `desktop/scripts/add-shortcut.ps1` 生成，
不用重建。
