- **类型+值**：58 个全是 `export *`，删掉会同时丢值与类型面；C 的 `approval` 只有类型（目标文件没有运行期值），`memory`/`mcp` 是值+类型。`src/services/types.ts:1648` 还对外透出 `ApprovalDecision/ApprovalRequest`，改 C-1 时别把这行一起删。
