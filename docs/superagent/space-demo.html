Super Agent

把一句话需求派给独占工作区的智能体，结果回到工单里

默认仓库路径
执行器在这个仓库里建工作树。改完保存，下一张工单就用新路径。
同时最多几个工单在跑
并发上限，1–16，默认 2。超出的工单排队等空位。
单工单超时（秒）
从建单起超过这个秒数还没结束就停掉并标为失败；0 表示不限。
GitHub 仓库
写成 owner/name。填上之后，那个仓库里 @ 机器人一句就会变成一张工单；留空表示不接 GitHub。
机器人的 GitHub 登录名
用它跳过机器人自己发的评论。填错会把它自己的回复也当成新需求，反复派活。
令牌所在的环境变量
默认读 GITHUB_TOKEN。令牌不落盘、不写进配置文件。
飞书来源
打开后从飞书群和私聊收需求。默认关；关着时一个 lark-cli 子进程都不会起。
要收的群
群的 chat_id（以 oc_ 开头），逗号分隔。留空就不收任何群。
改完即时写入 ~/.dsc/settings.json；这一格与插件中心里的那一份是同一个分区。
